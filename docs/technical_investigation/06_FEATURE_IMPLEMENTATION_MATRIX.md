## Cross-Platform Feature Inventory Across Android, Web, Admin & Backend

---

### Feature Status Classification Legend

- **COMPLETE**: Fully implemented in UI, connected to authoritative backend and database, verified by automated or manual tests.
- **PARTIALLY COMPLETE**: Core logic exists on both sides, but contains build/type discrepancies, incomplete edge cases, or missing fields.
- **UI ONLY**: Visual screen and client state exists, but submits to mock state or disconnected endpoints.
- **BACKEND ONLY**: Server handlers, database tables, and migrations exist, but no corresponding native UI screens have been wired.
- **MOCKED**: Operates purely against local static fixtures or simulated memory timeouts without persistence.
- **BROKEN**: Runtime or build exceptions prevent execution.
- **NEEDS VERIFICATION**: Implemented in code, requires live physical environment testing (e.g. native SIM card STK push).
